# منصة إدارة حركة المركبات والمهام الميدانية (Fleet & Movement Management)

لوحة إدارة عربية RTL (PHP + MySQL) + API آمنة + تطبيق Android أصلي (Kotlin) للسائقين، مصمَّمة للاستضافة المشتركة/cPanel دون صلاحيات root أو عمليات دائمة.

> **الحالة:** تنفيذ كامل للمراحل 1–7 برمجيًا مع اختبارات؛ المرحلة 8 (staging والإنتاج) **لم تُنفَّذ** وتنتظر موافقتك وأسرارك. انظر [«ما اختُبر وما لم يُختبر»](#ما-اختُبر-وما-لم-يُختبر).

## البنية
```
backend/    PHP 8.1+ (API + لوحة الإدارة + cron) — migrations، اختبارات PHPUnit
android/    core (منطق JVM مختبر) + app (Compose، Room، WorkManager، خدمة موقع أمامية)
docs/       المعمارية، ADRs، ERD، OpenAPI، النشر، التكاملات، النسخ الاحتياطي، سياسة الموقع
.github/    CI (PHP+MySQL، Android، فحص أسرار)، نشر staging/إصدار APK (يدوي بموافقة)
```

## الميزات المنفّذة
| المجال | ما نُفّذ |
|---|---|
| الصلاحيات | أدوار متعددة، 30 صلاحية دقيقة، نطاقات (فريق/منطقة/أسطول)، تحقق خادم لكل طلب، MFA/TOTP، قفل الحساب، تحديد المعدل، تدقيق بسلسلة تجزئة |
| المهام | آلة حالات (مسودة→…→مكتملة/ملغاة) + سجل أحداث، رفض بسبب إلزامي، إعادة إسناد، تعارض المركبة مع استثناء موثق، إثبات بالصور، مسارات بإصدارات واعتماد |
| التتبع | قبول المهمة يبدأ GPS تلقائيًا، رحلة واحدة لعدة مهام دون تكرار المسافة/التوقفات، مراحل مركبة بعدادين، دفعات GPS idempotent، توقفات (3/5/10 د قابلة للضبط)، انحراف عن المسار، حالة اتصال صادقة (لا موقع قديم كمباشر) |
| الطوارئ | SOS بأقل مدخلات، offline محفوظ «بانتظار الاتصال»، دورة حياة كاملة، إجراءات، تصعيد من cron مع بديل، قناة SMS احتياطية (غير مضمونة) |
| الأوفلاين | Room + outbox، أولويات المزامنة، backoff، حل تعارض الإلغاء، مركز مزامنة، صور بحالة واضحة |
| SMS | تنبيه فقط بعد مهلة، أربع حالات منفصلة، مزود قابل للاستبدال |
| اللوحة | 13 قسمًا: مؤشرات، مهام (معالج 4 خطوات)، خريطة مباشرة، مركبات، سائقون، توقفات/انحرافات، SOS، عدادات، فحص/وقود (مفعّلان بالإعداد)، تقارير CSV/XLSX/طباعة PDF، مستخدمون/أدوار، إعدادات، تدقيق |

## التشغيل المحلي (تطوير)
```bash
cd backend && composer install
cp .env.example .env   # املأ DB_*
php bin/migrate.php
ADMIN_PASSWORD='كلمة-قوية-طويلة' php bin/create-admin.php admin "مدير النظام"
php -S 127.0.0.1:8080 -t public public/router.php
```
الاختبارات (تتطلب MySQL/MariaDB وقاعدة `fleet_test` ومستخدم `fleet/fleet` أو متغيرات `TEST_DB_*`):
```bash
cd backend && vendor/bin/phpunit
cd ../android && ./gradlew -PcoreOnly=true :core:test      # منطق Android بدون SDK
cd ../android && ./gradlew :app:assembleDebug              # يتطلب Android SDK
```

## ما اختُبر وما لم يُختبر
| البند | الحالة |
|---|---|
| Backend (PHP/MySQL): 54 اختبار وحدة/تكامل/صلاحيات/API | ✅ يعمل محليًا ويُشغَّل في CI |
| Android `core` (منطق JVM): 11 اختبارًا | ✅ |
| Android `app` (واجهة/Room/خدمة الموقع) | ⚠️ **لم يُبنَ محليًا** (لا Android SDK في بيئة التطوير). يُبنى أول مرة في CI؛ توقّع إصلاحات تجميع طفيفة |
| لقطات واجهة اللوحة (RTL، موبايل/ديسكتوب) | ✅ فُحصت بمتصفح headless |
| اختبار ميداني GPS/بطارية/force-stop على أجهزة حقيقية | ❌ يلزم قبل الإنتاج |
| مزود SMS/Firebase/Routing الحقيقية | ❌ بانتظار حساباتك؛ مُنفّذ خلف واجهات + بيئة اختبار |
| PDF من الخادم بالعربية | ⚠️ الطباعة→PDF من المتصفح (شكل عربي سليم)؛ توليد PDF خادمي يتطلب مكتبة (mPDF) — قرار معلّق |
| staging / production / FTP | ❌ لم يُنفَّذ؛ بانتظار موافقتك |

## الأمان بإيجاز
HTTPS فقط، Argon2id، رموز Bearer مجزأة (SHA-256) مع تدوير ومنع إعادة الاستخدام، CSRF للويب، استعلامات مُعدّة (PDO)، تهريب افتراضي للمخرجات، رفع ملفات بفحص MIME وsha256 وتخزين خارج الويب، CORS مغلق افتراضيًا، لا أسرار في المستودع (فحص gitleaks في CI).
