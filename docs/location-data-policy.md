# سياسة بيانات الموقع والخصوصية

1. **لا تتبع خارج المهام:** يبدأ التسجيل عند قبول مهمة ويتوقف بعد إغلاق كل مهام الرحلة. الاستثناء الوحيد: موقع بلاغ SOS.
2. **الإشعار الدائم** يخبر السائق بأن التتبع نشط. شاشة «الخصوصية» في التطبيق تشرح ما يُجمع.
3. **من يرى ماذا:** المشاهدة المباشرة تتطلب `tracking.view_live`، والتاريخية `tracking.view_history`، وكلاهما ضمن نطاق الوصول. كل اطلاع تاريخي أو على صورة يُسجل في التدقيق.
4. **الاحتفاظ:** نقاط GPS للرحلات المغلقة تُحذف بعد `retention.gps_days` (افتراضي 180؛ 0 = دائم) عبر cron. الملخصات (المسافة، التوقفات، الانحرافات) تبقى. التدقيق `retention.audit_days` (730).
5. **الصور:** تُخزن خارج الويب وتُقدَّم عبر نقطة مصرّح بها فقط (لا رابط عام).
6. **بيانات الركاب/الوفد:** حقل `party_info` نصي حر؛ لا تُدخل بيانات شخصية حساسة أكثر من اللازم. يُصدَّر في التقارير فقط ما يلزم.
7. **الوصول للبيانات من السائق:** يرى مهامه وسجله فقط.
8. **حقوق الأفراد:** يمكن لمسؤول النظام تعطيل حساب سائق (يبطل رموزه) وتصدير/حذف بياناته بطلب مبرر وفق سياسة المؤسسة (تدقيق مطلوب).
9. **استنتاجات الهاتف** (توقف، انحراف، فرق العداد/GPS) أدوات مراجعة وليست دليلًا قطعيًا على مخالفة.

> ينبغي مراجعة هذه السياسة قانونيًا/لدى إدارة الموارد البشرية والحصول على موافقة السائقين قبل التشغيل.
