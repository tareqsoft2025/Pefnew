# ADR 0002 — المزامنة: HTTP outbox + idempotency (بلا WebSocket)

**الحالة:** مقبول

## القرار
- التطبيق يحفظ كل شيء محليًا (Room) ثم يرسل: **outbox أحداث** عبر `POST /sync/events` (حتى 200، `event_id` فريد)، **دفعات GPS** عبر `POST /gps/batch` (حتى 500، معرف نقطة فريد)، ثم **الصور** multipart مع sha256، ثم **pull** للمهام.
- الخادم يخزن نتيجة كل حدث في `sync_events` ويعيد النتيجة نفسها عند التكرار (`status: duplicate`).
- أولوية الإرسال: SOS ← قرارات المهام ← باقي الأحداث ← GPS ← الصور.
- حالات النتيجة: `applied | duplicate | conflict | rejected | retry`. `retry` (اعتماد على حدث لم يصل بعد) لا يُخزَّن ولا يُحذف من outbox.
- التعارض: إن ألغى المدير مهمة أثناء انقطاع السائق يرد الخادم `conflict` مع `server_mission` فيطبقها التطبيق ويعرض سبب التعارض.
- لا حذف محلي قبل تأكيد الخادم؛ نقاط GPS المرفوعة تُنظّف بعد 24 ساعة.

## البدائل
WebSocket/SSE: يتطلب عملية دائمة غير متاحة في الاستضافة المشتركة (انظر `docs/hosting-constraints.md`).
