# ADR 0006 — سجل تدقيق بسلسلة تجزئة

على الاستضافة المشتركة قد لا تتوفر صلاحيات إنشاء triggers لمنع UPDATE/DELETE. لذلك: التطبيق لا يكتب إلا INSERT، وكل صف يحمل `prev_hash` و`row_hash = sha256(prev|الحقول)`. صفحة «سجل التدقيق» تشغّل `verify()` وتنبّه عند كسر السلسلة. يوصى إضافة مستخدم قاعدة بيانات للتطبيق بلا صلاحية DELETE/UPDATE على `audit_logs` إن أمكن.
