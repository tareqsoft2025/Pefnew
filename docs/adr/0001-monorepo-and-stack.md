# ADR 0001 — monorepo وحزمة تقنية ملائمة للاستضافة المشتركة

**الحالة:** مقبول (بانتظار موافقة المالك)

## السياق
المطلوب منصة إدارة حركة (PHP/MySQL + Android Kotlin) قابلة للنشر على cPanel دون صلاحيات root أو عمليات دائمة.

## القرار
- مستودع واحد: `backend/` (PHP 8.1+، بلا إطار ثقيل، PDO، migrations SQL)، `android/` (وحدتان: `core` JVM مختبرة و`app`)، `docs/`، `.github/`.
- بلا إطار PHP كبير: تقليل سطح الهجوم والحجم وسهولة الرفع اليدوي على cPanel؛ `composer install` يلزم فقط لأدوات التطوير. (التطبيق نفسه لا يعتمد على حزم وقت التشغيل.)
- migrations ملفات SQL مرقمة بمشغّل صغير (`bin/migrate.php`) يعمل من سطر الأوامر أو cron/المتصفح عند الحاجة.

## العواقب
+ نشر بسيط (نسخ ملفات + `.env`)، + اختبارات سريعة على MySQL حقيقي.
− نكتب Router/Validator صغيرين بأنفسنا (مغطيان بالاختبارات)؛ يمكن الانتقال لاحقًا إلى Slim/Laravel دون تغيير الخدمات (Services معزولة عن HTTP).
