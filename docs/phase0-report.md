## 7. قرارات غير محسومة (أحتاج قرارك)
1. **مستوى إلزام فحص المركبة:** اختياري حاليًا خلف `feature.inspection` (+`feature.inspection_mandatory` غير مفعّل برمجيًا للإلزام بعد).
2. **مزود SMS** (Unifonic/Taqnyat/Twilio…): الفئة `HttpSmsProvider` عامة وتحتاج مطابقة واجهة المزود.
3. **مزود الخرائط/البلاطات والـ Routing:** OSM العامة للتجارب فقط؛ الإنتاج وخرائط offline تتطلب مزودًا مرخّصًا أو خادمًا خاصًا.
4. **Push عبر Firebase:** هل تُسمح بإرسال بيانات المهام (عناوين فقط) عبر طرف ثالث؟ حاليًا الإشعار عنوان/نص قصير.
5. **PDF خادمي بالعربية:** طباعة المتصفح حاليًا؛ mPDF أم خدمة أخرى؟
6. **فترات الاحتفاظ:** 180 يومًا لـ GPS و730 للتدقيق افتراضيات تحتاج اعتمادًا قانونيًا.
7. **تشفير قاعدة Room (SQLCipher):** غير مفعّل؛ هل يشترطه نموذج التهديد؟
8. **توقيت العرض:** UTC+3 ثابت؛ هل تحتاج منطقة زمنية لكل مستخدم؟
9. **خوادم الاستضافة:** إصدار PHP/MySQL الفعلي، وهل SSH متاح للنشر (rsync) أم cPanel Git/File Manager فقط؟
10. **نطاقات الوصول:** نموذج AND بين الأنواع وOR داخل النوع — تأكد أنه يناسب هيكلكم التنظيمي.

## حدود معروفة
- GPS في الخلفية على Android ليس مضمونًا (البطارية/الإيقاف القسري/الإذن) — الواجهة تعرض الحالة بصدق ولا تعد باستمرارية.
- تصنيف التوقف/الانحراف/فرق العداد استدلالات تحتاج مراجعة بشرية.
- `TripAnalyzer` يعيد تحليل كل نقاط الرحلة عند كل دفعة (O(n))؛ مناسب لآلاف النقاط/رحلة، ويحتاج تحسينًا تزايديًا لرحلات ضخمة.
